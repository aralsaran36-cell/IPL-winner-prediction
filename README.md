# 🏏 IPL Winner Prediction

A Machine Learning project that predicts **IPL match winners** based on historical match data using classification algorithms.

---

## 🎯 Problem Statement

IPL is one of the most watched cricket leagues in the world. This project uses historical match data to predict which team is likely to win — based on teams, venue, toss, and other match features.

---

## 🧠 How It Works

```
IPL historical match data
        ↓
Data Cleaning & Preprocessing
        ↓
Feature Engineering (teams, venue, toss, season)
        ↓
Train classification models
        ↓
Predict match winner
```

---
